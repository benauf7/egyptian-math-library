# مكتبة الرياضيات الشخصية (Personal Mathematics Library)
### أرشيف المناهج المعتمدة رسمياً في مصر من الصف الرابع الابتدائي حتى أولى بكالوريا (2020 - 2027)

تطبيق ويب تعليمي شامل، عالي الأداء ومكتمل الإنتاج (Production-Ready) صُمم ليكون المرجع الشخصي الأكاديمي الدائم لمراجعة جميع معارف وقوانين ومناهج الرياضيات التي درسها الطالب في مسيرته المدرسية المصرية، مع الالتزام الصارم بتوثيق **المنهج القديم** الذي درسه الطالب قبل وصول تغييرات وتطويرات نظام التعليم 2.0 لكل صف دراسي، وصولاً إلى منهج **أولى بكالوريا (الصف الأول الثانوي)** المعتمد للعام الدراسي الحالي **2026/2027**.

---

## 🌟 ميزات التطبيق الرئيسية

1. **التحقيق الأكاديمي الصارم للمناهج والسنوات الدراسية:**
   - نظام Versioning كامل يمنع تسرب أو خلط أي محتوى من المناهج الحديثة لصفوف المنهج القديم.
   - التحقق من السنوات: رابعة ابتدائي (2020/2021)، خامسة (2021/2022)، سادسة (2022/2023)، أولى إعدادي (2023/2024)، ثانية إعدادي (2024/2025)، ثالثة إعدادي (2025/2026)، وأولى بكالوريا (2026/2027).
   - توثيق كتب وزارة التربية والتعليم والتعليم الفني والقرارات الوزارية لكل صف وسنة دراسية.

2. **قسم مخصص للأساسيات والتريكات الشائعة (Foundations & Edge Cases):**
   - قواعد الإشارات (الجمع، الطرح، الضرب، القسمة).
   - ترتيب إجراء العمليات الرياضية (الأولويات الحسابية).
   - جمع وطرح وضرب وقسمة الكسور الاعتيادية بطريقة المقص السريعة.
   - تدرج مجموعات الأعداد في مسيرة الطالب (ط ⊂ ص ⊂ ن ⊂ ح ⊂ ك).
   - الحالات الشاذة والمطبات القاتلة في الامتحانات (مثل س² = ٩ ⟹ س = ±٣ ، ومجموع المربعين لا يتحلل في ح، وميل المستقيم الرأسي غير معرف).
   - جدول تحويلات وحدات القياس (الأطوال، المساحات، الحجوم، والزوايا).

3. **الصياغة والأمثلة بالرموز العربية الأصيلة للمنهج المصري:**
   - التزام تام بالرموز والأسلوب المدرسي المصري (س، ص، ع، أ، ب، جـ، ل، م، نق، ط).
   - شرح مبسط ومباشر يركز على الفهم الفوري والربط بالتطبيقات الحياتية.

4. **واجهة مستخدم عصرية بشريط جانبي (Right Sidebar):**
   - شريط تنقل جانبي كامل في اليمين (RTL) يتضمن كافة الأقسام مع الحفاظ على مساحات مريحة للقراءة.
   - شريط علوي خفيف مخصص حصرياً للبحث الشامل الممتد، زر التحويل للوضع الليلي، وزر الطباعة.

5. **عرض المعادلات الرياضية الاحترافي (KaTeX):**
   - صيغ رياضية مكتوبة بترميز LaTeX الصارم، مع دعم اتجاه LTR للمعادلات و RTL للنصوص التوضيحية العربية.

6. **الدروس المتكاملة بنظام الـ 20 نقطة التعليمية:**
   - كل درس يحتوي على: اسم الدرس، الصف، السنة، الوحدة، المفاهيم الأساسية، التعريفات، القوانين، الرموز، شرح القانون، متى يستخدم، خطوات الحل، 4 أمثلة متدرجة (بسيط، متوسط، متقدم، تطبيقي)، الأخطاء الشائعة، طرق الاختصار، العلاقات الرياضية، والقوانين المرتبطة والمصدر.

7. **قسم التحليل الرياضي المتخصص (Factoring Suite):**
   - تفصيل شامل لكافة طرق التحليل: إخراج العامل المشترك (ع.م.أ)، المقدار الثلاثي البسيط، غير البسيط (بالمقص)، المربع الكامل، فرق المربعين، مجموع وفرق المكعبين، التحليل بالتقسيم، والتحليل بإكمال المربع.

8. **قسم طرق وخوارزميات حل المسائل:**
   - طرق حل المعادلات الخطية والتربيعية، تحويل المسائل اللفظية إلى معادلات، التقسيم التناسبي ومقياس الرسم، براهين الهندسة الاستدلالية، تبسيط الدوال الكسرية، وبحث إشارة الدالة.

9. **قسم مخصص: "إضافات رياضية خارج المنهج":**
   - عزل كامل لأي قوانين متقدمة أو إثرائية (مثل صيغة هيرون ورباط الحذاء) حتى لا تختلط بالمنهج الإلزامي.

10. **البحث الشامل والمتقدم والفلاتر الذكية:**
    - يدعم البحث باللغة العربية، الإنجليزية، والرموز وصيغ المعادلات، مع فلاتر بالمرحلة، الصف، السنة الدراسية، والنوع.

11. **الخط الزمني التفاعلي ("رحلتي في الرياضيات"):**
    - استعراض تفاعلي مسار السنوات من 2020/2021 إلى 2026/2027، بالضغط على أي سنة تظهر كافة مواضيعها.

12. **لوحة التحكم والمتابعة (Dashboard):**
    - إحصائيات دقيقة، متتبع لآخر ما تمت مراجعته، قائمة الموضوعات التي تتطلب مراجعة، وشريط تقدم للمراجعة.

13. **المفضلة وحالة المراجعة المحلية (Local-First):**
    - حفظ محلي فوري وسريع (LocalStorage) دون الحاجة لخادم خلفي.

14. **تصدير كتاب المكتبة الكامل بصيغة PDF والطباعة الاحترافية:**
    - يدعم الغلاف، الفهرس العام، فهارس القوانين والتحليل والمصادر، مع تناسق كامل للخطوط العربية (Cairo و Amiri) وترقيم الصفحات.

## 🛠 التقنيات المستخدمة (Tech Stack)

- **Frontend Framework:** React 18 + TypeScript
- **Bundler & Build Tool:** Vite 5
- **Styling:** Tailwind CSS (مع دعم الوضع الليلي Dark Mode وتنسيقات الطباعة Print Mode)
- **Math Rendering:** KaTeX 0.16
- **Icons:** Lucide React
- **Data Architecture:** Local TypeScript Data Layer مع فهارس واسترجاع فوري
- **Testing & Validation:** Vitest 2 + Node ESM Validation Script

## 🚀 كيفية تشغيل وبناء المشروع

### 1. تثبيت الحزم (Dependencies):
```bash
npm install
```

### 2. تشغيل المشروع في بيئة التطوير (Dev Server):
```bash
npm run dev
```
سيعمل التطبيق محلياً على: `http://localhost:3000`

### 3. تشغيل سكربت التحقق الأكاديمي للمناهج (Validation Script):
```bash
npm run validate
```
يقوم هذا السكربت بفحص كل درس وقانون والتأكد من مطابقة السنة الدراسية للصف الدراسي وعدم تسرب أي منهج حديث إلى المناهج القديمة.

### 4. تشغيل الاختبارات الآلية (Test Suite):
```bash
npm test
```
تشغيل جميع اختبارات Vitest (18 اختباراً لوظائف البحث، الفلاتر، سلامة KaTeX، التخزين، والمناهج).

### 5. بناء نسخة الإنتاج (Production Build):
```bash
npm run build
```
يقوم بفحص الأنواع البرمجية عبر TypeScript أولاً ثم حزم المشروع عبر Vite داخل مجلد `dist/`.

## 📝 دليل إدارة وتعديل المحتوى

تم عزل جميع البيانات بالكامل داخل مجلد `src/data/` بصيغة TypeScript واضحة لتسهيل الإضافة والتعديل دون الحاجة لتعديل كود الواجهة:

### 1. كيفية إضافة درس جديد (`src/data/lessons/`):
افتح الملف المناسب لمرحلة الدرس (مثلاً `prep_lessons.ts`) وأضف كائناً جديداً يتبع واجهة `MathLesson`:
```typescript
{
  id: 'lesson_unique_id',
  title: 'اسم الدرس',
  title_en: 'Lesson Title in English',
  grade_id: 'prep_2',
  grade_name: 'الصف الثاني الإعدادي',
  stage_id: 'prep',
  academic_year: '2024/2025',
  curriculum_version: 'egyptian_old_curriculum',
  term: 2,
  unit_number: 1,
  unit_name: 'الوحدة الأولى',
  lesson_number: 2,
  branch: 'الجبر',
  key_concepts: ['مفهوم 1', 'مفهوم 2'],
  definitions: [{ term: 'المصطلح', definition: 'التعريف الدقيق' }],
  formula_ids: ['form_id_1'],
  used_symbols: [{ symbol: 'x', meaning: 'المتغير' }],
  formula_explanation: 'شرح مبسط وواضح للقانون...',
  when_to_use: ['متى نستخدم هذا القانون في المسائل'],
  solution_steps: ['الخطوة 1', 'الخطوة 2'],
  examples: [
    { title: 'مثال بسيط', level: 'بسيط', question: '...', solution_steps: ['...'], final_answer: '...' },
    { title: 'مثال متوسط', level: 'متوسط', question: '...', solution_steps: ['...'], final_answer: '...' },
    { title: 'مثال متقدم', level: 'متقدم', question: '...', solution_steps: ['...'], final_answer: '...' },
    { title: 'مثال تطبيقي', level: 'تطبيقي', question: '...', solution_steps: ['...'], final_answer: '...' }
  ],
  common_mistakes: ['خطأ شائع يحذر منه'],
  shortcuts_and_tricks: ['حيلة رياضية سريعة'],
  source: OFFICIAL_SOURCES.moete_prep_2_old
}
```

### 2. كيفية إضافة قانون جديد (`src/data/formulas/`):
افتح ملف القوانين المعني (مثال: `sec_formulas.ts`) وأضف القانون بصيغة `MathFormula`:
```typescript
{
  id: 'form_sec1_example',
  name: 'اسم القانون',
  name_en: 'Formula Name',
  latex: 'E = mc^2',
  grade_id: 'sec_1',
  grade_name: 'أولى بكالوريا (الصف الأول الثانوي)',
  stage_id: 'secondary',
  academic_year: '2026/2027',
  curriculum_version: 'egyptian_restructured_2024_2027',
  branch: 'الجبر',
  unit_name: 'الوحدة الأولى',
  topic: 'الموضوع',
  symbol_definitions: [{ symbol: 'm', meaning: '...' }],
  meaning_explanation: 'شرح معنى القانون الرياضي...',
  when_to_use: ['حالات الاستخدام'],
  solution_steps: ['خطوة 1', 'خطوة 2'],
  example: { problem: '...', solution_steps: ['...'], answer: '...' },
  notes: ['ملاحظة هامة'],
  source: OFFICIAL_SOURCES.moete_sec_1_restructured
}
```

### 3. كيفية إضافة سنة دراسية جديدة:
1. افتح `src/data/types.ts` وأضف السنة في نوع `AcademicYear`.
2. افتح `src/data/curriculum/grades.ts` وأضف كائن الصف الجديد ببيانات الكتاب الرسمي وتوصيف المنهاج.
3. حدد نوع المنهج (`curriculum_version`).

## 🖨️ كيفية إنشاء وتصدير كتاب المكتبة (PDF)

1. ادخل على تبويب **"كتاب المكتبة (PDF)"** من الشريط العلوي.
2. يمكنك اختيار طباعة **الكتاب كاملاً** أو تخصيص الطباعة للمرحلة الابتدائية، الإعدادية، أو أولى بكالوريا فقط.
3. اضغط على زر **"حفظ كـ PDF / طباعة فورية"**.
4. في نافذة الطباعة المنبثقة من المتصفح:
   - اختر الطابعة: **Save as PDF** (حفظ بتنسيق PDF).
   - حجم الورق: **A4**.
   - خيارات الرسوم الخلفية: فعل خيار **Background graphics** لضمان ظهور التنسيقات والألوان الدقيقة.
5. اضغط **Save** لتحصل على كتاب الرياضيات الشخصي الكامل بأعلى جودة عربية وصيغ KaTeX نقية.
